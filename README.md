## 제출물 8종 / Eight submissions

① 저장소 URL ② 실행 가능한 결과물 ③ 시연 영상(3분) ④ README.md
⑤ PROMPTS.md ⑥ 결과보고서 ⑦ 발표자료 ⑧ 개인 성찰문

**결과보고서는 백지에서 쓰지 않습니다.** 매주 활동지를 엮어 완성합니다.

## AI 사용 규칙 / Rules for using AI

1. AI 사용은 **허용**합니다. 단 주요 판단과 근거를 `PROMPTS.md`에 기록합니다.
2. **이해하지 못한 코드는 제출하지 않습니다.** 발표에서 동작 원리를 질문합니다.
3. 타인의 코드를 출처 표기 없이 사용하지 않습니다.
4. **실제 개인정보를 AI 도구의 컨텍스트로 제공하지 않습니다.**

> AI를 쓰는 것은 부정행위가 아닙니다. **감추는 것**이 부정행위입니다.

## 윤리 노트 / Ethics Notes

2~7주차에 매주 사례 하나와 질문 두 개가 주어집니다. **개인**이 150~300자로 작성해 활동지에 커밋합니다.
정답을 채점하지 않습니다. **근거를 쓰는 것**이 목적입니다. 15주차 회고에서 6편을 다시 읽습니다.
